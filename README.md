# Akthomee — Portfolio

> Personal portfolio site for **Akthomee**, a software developer building clean, scalable web products — from first line of code to final deploy.

**Live site:** [akthomee.com.ng](https://akthomee.com.ng)

---

## What's inside

A single-page portfolio plus inner pages that showcase:

- **Websites** — client projects (GameRock, Venera, Nuso Jewels, Rustic Cuisine, Tmonney, Apex Autos, VoidXplore)
- **Mini-projects** — small vanilla HTML/CSS/JS builds with a built-in source-code viewer
- **Apps** — mobile apps (FYB Card, Goal Grid)
- **Books** — published writing (50+ Dreams & Interpretations)

Each portfolio item opens a modal with project details, and mini-projects include a syntax-highlighted source viewer that fetches real files from the repo.

---

## Features

- **5 themes** — Night, Day, Forest, Sunset, Ocean — persisted to `localStorage`
- **Responsive layout** — sidebar on mobile, horizontal top bar on desktop, no media-query hacks
- **CSS-only interactions** — dropdown menus, header toggle, and nav animations use pure CSS
- **Isotope-powered portfolio grid** — filterable, shuffled on load, see-all cards pinned to bottom
- **In-page source viewer** — HTML/CSS/JS tabs, copy-to-clipboard, syntax highlighting via Prism.js
- **Lightweight** — no frameworks, no build step, no dependencies beyond CDN libraries
- **Accessible** — semantic markup, ARIA labels on interactive elements, keyboard-friendly dropdowns
